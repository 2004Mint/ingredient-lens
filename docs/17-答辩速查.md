# 答辩速查（省赛材料 / 国赛现场）

> 用法：上台前 10 分钟看一遍。左边是问题，右边是**能一句话说完**的答案；后面附数据口径与兜底方案。
> 原则：不背稿，背「事实 + 判断」。评委追问细节时，能指到代码或文档。

## 一、三个长度的开场

**30 秒版**

> 成分表按含量降序排列，这条规则公开、可验证，但没人拿它做推理。成分镜把「排在第几位」翻译成对你的一句话结论：该避开什么、哪些功效是概念添加、哪些限量要注意。判定全部交给规则，模型只负责把结论说成人话，而且每句话都能回溯到规则或成分库。

**90 秒版**

> 一瓶号称烟酰胺美白的精华，烟酰胺排第 12 位——前面还有 11 个成分，它不可能是主要功效来源。这是「概念添加」。
> 成分镜做三件事：按排位识别概念添加、按你的肤质/敏感/孕期重排风险、把结论变成能复制能分享的报告。
> 我们不评价商品好坏、不做成分评分、不带货：只读标签信息，把不可证的推断挡在门外。
> 技术上，规则引擎负责判定，大模型只做「解释」；解释要过输出闸门（不许出现数字/百分比/医疗用语），失败自动回退模板；未收录成分由 Agent 查证后自动入库，带依据与置信度。

**3 分钟版**：按 `docs/05-演示视频脚本-省赛版.md` 的 S1–S11 走，不要即兴加功能。

## 三、高频问题（按被问概率排序）

**1. 为什么不直接用大模型判断？**
判定必须可复现、可追责。同一个成分表，今天和明天必须得出同一结论；模型做不到，规则表可以。模型只负责「把已确定的事实说人话」，输出还要过闸门。

**2. 为什么不用向量检索？**
实体匹配不能容错：「1,2-戊二醇」和「1,2-丙二醇」在向量空间很近，但一个是普通保湿剂、一个是不同物质；「羟苯甲酯」和「羟苯丙酯」限量不同。匹配错就是安全事故，所以中文名一律精确匹配。
（如果追问 RAG：检索和匹配是两层。法规原文/同类成分的**知识检索**可以做 BM25 + 向量混合，返回带 source 的片段；**实体识别**仍然精确。这是我们下一步要补的。）

**3. 怎么保证模型不编造？**
四道：事实由规则给（不含数字）、提示词禁止数字与医疗用语、输出闸门逐条检查、不过关整段回退模板。评测里 5 条护栏全部真实调用，0 次越界。

**4. 准确率多少？**
不说「准确率」，说可复现的口径：22 个产品场景 + 5 条护栏，全部可在 `docs/eval` 复跑；48 个后端单测锁住判定与闸门。原先唯一的已知问题（水杨酸辛酯被包含匹配归到水杨酸）已经修掉，并转成回归用例 A22。

**5. 和美丽修行/真我有什么区别？**
它们是「成分百科 + 商品评分/社区」，我们不做评分、不做商品库、不带货；我们做的是「按你的档案，对**这一瓶**给一句可核对的结论」，并且把依据和置信度摊开给你看。

**6. 商业模式？**
C 端订阅（多瓶管理/对比）、B 端 API（内容创作者/电商详情页）、私有化部署（品牌合规）。单次解释成本 < ¥0.01，研究 < ¥0.05，1 万日活约 ¥300/日；3% 付费可覆盖。详见 README「商业与成本」。

**7. 隐私怎么保证？**
文本分析在本机完成，不上传；照片只发给**你自己配置的**视觉服务；报告历史只存浏览器，分享报告存本机、30 天清理；公开仓库不含任何 Key（CI 也会跑）。

**8. 模型挂了怎么办？**
先重试一次完整生成；仍失败回退本地模板，并在界面上说明「本地解释」。研究队列失败会保留错误与重试时间，管理台可重试；不会假装成功。

**9. 为什么用 Vue 而不是 React/Next？**
团队熟悉 Vue 3 + Vite，构建产物小、开发反馈快；评分细则允许 Vue 3 体系。省赛后计划补 TypeScript 与路由级代码分割（已经做了懒加载与分包）。

**10. 你们最难的取舍是什么？**
「不做」比「做」难：不做评分、不做带货、不让模型碰判定、不在研究没完成时给结论。每一次「不做」都对应一个具体的错误场景。

## 五、现场兜底

- **断网**：示例配方、规则分析、报告、历史、打印全部可用；只有解释/研究/识别会降级，界面会注明「本地解释」。
- **没配 Key**：视觉入口自动隐藏，文案从「拍一下」变「粘一下」；研究接口关闭但报告照常出。
- **模型很慢**：先录屏/截图兜底；现场演示优先走「示例 + 已完成的 AI 描述」，不要赌实时模型。
- **被问住**：说「这块还没做，我们的取舍是 X，下一步是 Y」，比现编强。评委反感的是编，不是没有。

## 六、不要说的话

- 「我们的 AI 能判断成分安不安全」——我们只解释标签，不下安全结论。
- 「准确率 95%」——没有这个口径，别造数。
- 「用了 RAG」——目前没有，别把「精确匹配」说成 RAG。
- 「替代医生/药师」——明确不做医疗建议。
