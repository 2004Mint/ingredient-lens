# 成分镜 · 演示视频自动化流水线

> 产出：`video/out/成分镜-完整版-5分37秒.mp4`（1920×1080 / H.264 / AAC / 5:37.6 / 38 条字幕）
> 配音：Breeze-TTS-2.cpp 保存音色 **xiaojingyu（小鲸鱼）**
> 录屏：capture-director（Playwright + CDP screencast）

---

## 一、为什么是这条流水线

目标不是"随便录一段"，而是**口播、画面、字幕三者帧级对齐**，改一句话能十分钟重出全片。

所以顺序是 **配音先行**：

```
narration.json（每句一行）
   ↓ TTS 逐句合成
audio/sX-N.wav（每句独立文件）
   ↓ ffprobe 量时长
durations.json
   ↓ build.mjs 计算
shots/full.yaml + shots/full-timeline.yaml + sub/*.txt + sub/filter.txt
   ↓ capture-director
11 段 1080p 片段 → render（硬切）→ full-silent.mp4
   ↓ ffmpeg 流拷贝混音轨 + drawtext 烧字幕
out/成分镜-完整版-5分37秒.mp4
```

关键取舍：**每句旁白一个 wav**。这样字幕时间轴由音频真实时长算出，不需要 ASR，也不会出现"字幕比人声慢半拍"。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File E:\AIWEB\video\make-video.ps1
```

它做五件事：登录后台取令牌 → `build.mjs` 生成分镜/时间轴/字幕 → 录制 11 镜 → 渲染无声片 → 混入配音并烧字幕。

改一句旁白：编辑 `video/narration.json` → 重跑 `tts-batch.ps1`（只补新句子也行）→ 再跑 `make-video.ps1`。

## 四、依赖与 Windows 适配

| 依赖 | 说明 |
|---|---|
| ffmpeg | `tools/ffmpeg`（BtbN 静态版，含 libx264） |
| Edge | `CD_CHROME_CHANNEL=msedge`；**Edge 156 必须 `CD_NO_SANDBOX=1`**，否则 headless 直接 `Target crashed` |
| breeze-server | `http://127.0.0.1:8080/v1/audio/speech`，`voice=xiaojingyu`；CLI 版写 WAV 会失败，走 HTTP |
| Node 22 | capture-director 只依赖 `playwright-core` + `yaml` |

踩过的坑，都在脚本里处理了：

1. **无限 `apad`**：`-af apad` 不给时长会让 ffmpeg 永远编码不完；改用 `apad=whole_dur=N` + `-t N`。
2. **libass 字号爆炸**：`subtitles` 滤镜默认按 384×288 脚本分辨率渲染，字号被放大 5 倍；改用 `drawtext + textfile`，中文不转义、尺寸确定。
3. **PS 5.1 把 stderr 当错误**：node 的进度日志走 stderr，`$ErrorActionPreference='Stop'` 会中断；改为重定向到日志 + 校验 `$LASTEXITCODE`。
4. **中文文件名传给 ffmpeg 会乱码**：先写 ASCII 名，再用 PowerShell 改名。
5. **JSON 带 BOM**：PS 5.1 的 `Set-Content -Encoding UTF8` 会写 BOM，Node 解析失败；统一用 `UTF8Encoding($false)`。
6. **技术卡按 1440×810 设计**：浏览器 viewport 是 1440×810 再放大到 1080p，按 1080 排版会溢出被裁。

## 五、已知限制

- **拍照识别镜头无法自动化**：Playwright 需要处理 `filechooser` 事件，capture-director 的 `click` 不支持注入文件。本片因此改为"粘贴 + 空格切分修复"路径，旁白也据此重写，**没有宣称拍照识别**。要补这一镜，需要人工录屏后拼入。
- **首页停留偏长**：S1 整段 48.5 秒都在首页，靠缓慢滚动撑场，信息密度偏低。
- **字幕底衬**：`drawtext` 的 box 是矩形底衬，压住页面底部内容，属于可读性优先的取舍。
- **数据污染**：录后台镜头前必须清掉测试成分/任务，否则会录进「庚辛壬」这类假数据（本次已清理 3 条）。
- **配速**：小鲸鱼原始语速约 330 字/分，整片已用 `atempo=0.9` 放慢到约 5:37；再慢会让句子拖沓。
